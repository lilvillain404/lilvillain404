 Мой интерес к данным появился ещё в университете, где я ежедневно работала с огромными массивами информации, искала в них закономерности. Эта работа заложила сильную фундаментальную базу в **математике** и **статистике**, которая стала основой моего аналитического мышления. Этот интерес остается со мной по сей день, и я активно продолжаю изучать новые технологии, инструменты и программы.
